## 第一轮真正要回答的问题

| 问题 | 最小信息 | 如何判断、如何改 |
|---|---|---|
| 能否安装并开始 | 下载版本、安装失败原因、素材就绪/开局耗时、首次操作 | 大量卡在开局先修兼容/加载；不能只统计成功进入的玩家 |
| 玩家是否理解操作 | 首次选中、下令、开始采集、建成建筑、训练兵的阶段与用时；求助次数 | 对同阶段退出者做短访谈，区分不知道操作与不想操作 |
| 在哪里停止 | 对局游戏时间、进度、最近里程碑；主动选择停止原因 | 后台、暂停、主动退出、胜败、崩溃疑似分别统计；不把缺少结束事件等同厌倦 |
| 是否有趣 | 想不想再来一局、最好/最差时刻、节奏/难度评价、实际再次开局 | 结合行为与原话；完局率高不等于有趣，时长长可能是拖沓 |
| 哪些战略可用 | 国家、地图、难度、时代、经济/军事里程碑、胜败、局长 | 按新手/熟手和相同难度分组；样本少时不据此直接改平衡 |
| 哪里卡顿 | build、Android/WebView 版本、设备档位、画质/省电设置、可见/活跃单位分桶、对局阶段 | 在同设备同设置复现，比较 p50/p95 和卡顿次数，而不是只看平均 FPS |
| 操作延迟在哪里 | 输入→指令接受→模拟首次执行→首帧可见反馈，各段本地耗时 | 单机先查主线程/模拟/绘制；联网再另测 RTT、服务器/锁步等待，不能混成“网络慢” |

观察到的里程碑需标注精度和口径：目前每 15 秒只读采样是“观察到已有军事单位/建筑/升时代”，不能当成首次训练完成，也可能错过短暂状态。准确事件应以后接入现有命令/事件接口并单独回归，不在模拟 hot path 上装通用计时包装。

## 两阶段采集

第一阶段：20–50 位自愿成年测试者，小范围邀请、免费、不含广告/付费。提供手动反馈与本地诊断分享。每周访谈约 5 人，记录玩家当时想达到的目标。优先解决无法开始、存档损坏、崩溃、严重卡顿，再处理引导与节奏。不用小样本做显著性或平衡承诺。

第二阶段：确认中美真实网络均可提交后再上线自建反馈接收服务与受保护统计页。行为统计、性能诊断、附件分开同意；拒绝不影响游戏。离线队列有容量上限，退避重试，服务端批次去重、校验和限流。上传在局外进行，不等待上传才能玩。先写清服务商、数据地区、隐私告知与删除渠道，再实际接收。

建议统一事件字段：schema、build/commit、channel、随机安装标识（只用于经同意的留存分析，可重置）、session/match 标识、事件名、相对用时、平台/系统与 WebView 主版本、语言、控制方式、地图/国家/难度、游戏进度分桶、设置。禁止上传完整点击坐标轨迹、逐帧录像或所有单位状态。

留存须定义：D1/D7 是有返回行为的独立同意安装数 / 有完整观察窗的首次安装数；重装/清除数据会影响口径，不宣称人数。漏斗分母从可测的首次打开起算，下载→安装需要另外的渠道数据。崩溃不能只靠 JS error；原生崩溃/ANR 以后单独接入。温度/耗电/内存不凭网页推断为真实硬件读数。

## 反馈表建议

当前表单提供主要问题类别、停止原因、是否愿意再玩（可跳过）和可空的文字说明；不提交也能正常玩。建议后续增补可跳过问题“是否首次玩 RTS”。问题类别包括：不知道下一步、操作困难、卡顿、过难、过易、节奏慢、错误、临时中断、其他。错误反馈让玩家描述“想做什么→实际发生什么→期望结果”，附件/存档须单独选择并预览。

首轮不收姓名、手机号、身份证、通讯录、定位、广告标识、聊天内容。国家/地区只需玩家可选“中国大陆/美国/其他”，不做精确定位；联系方式单独选填、不得混进匿名事件。随机标识仍可能构成个人数据，不称绝对匿名。

当前本地记录：最多 300 条、7 天；默认关；关闭后停止新增，清除按钮关闭记录并删除历史；导出由玩家主动操作。未来服务器建议原始事件保留 30 天，去标识汇总 90 天，手动反馈最多 90 天（除非玩家同意后续联系）。实施时需定时删除、验证、可凭反馈回执删除；基础设施访问日志/IP 的保留也须核实并告知。

## 每周迭代规则

每个候选改进要写：受影响版本/设备和玩家数、可复现证据、玩家原话、假设、改动、成功指标、守护指标。优先级按阻断程度×受影响范围×证据可信度÷成本，不按投诉音量排序。

例如：新手首兵之前停止且原因“不会造兵”→改善提示→比较同类新手首次训练成功率与用时；后期特定 Android 档位卡→固定地图和单位数复现→比较输入 p95、长任务、帧间隔和存档耗时，守护存档/确定性/电量；长局后评价重复→访谈后试一次节奏改动，比较再次开局意愿和实际再开局，不同时重做多个系统。

## 下载与发布验收

先产出可安装 APK，再启用下载按钮；显示版本、SHA256、包大小、Android 最低版本、安装步骤、已知问题、反馈入口。下载主备地址须在大陆与美国真实网络测首次下载、更新、损坏校验；GitHub Actions artifact 只供开发者取构建，不作为大陆玩家唯一下载渠道。微信内置浏览器必要时提示在系统浏览器打开。

使用固定包名和妥善备份的签名。首次测试包不得混称正式发行包；升级同签名安装且存档保留。飞行模式冷启动→新局→玩一局→存档→杀进程重启→恢复；横竖屏、安全区、系统返回、后台音频与暂停、分享文件都需 Android 真机。原生生命周期恢复未真机验证前不能称通过。

开工时电脑没有 Java、Android SDK、adb；本轮已下载校验 JDK 与官方 SDK，并使用临时英文目录解决 Windows 中文路径启动失败。Android 真机和中美网络验证未完成。APK 的实际构建状态见本轮验证记录；下载 URL 未配置、素材再分发清单/依赖许可证未完成核查前，不发布下载承诺。免费试玩也要保留素材来源记录。未来 iOS 隐私披露必须匹配真实实现，不能把默认关闭说成永不收集。
