# 电脑鼠标操作 + 建筑编队（feature/controls-groups，2026-11-24）

模块归属：界面（输入）。不改模拟代码；所有改变模拟的操作仍走 `sim.order` / `sim.train` / `sim.setRally`（单机直接执行，模拟 Worker 转发，联机锁步作为指令广播）。判定逻辑是 `src/ui/controls.js` 里的纯函数（`window.KingdomCore.controls`），`expansion.js` 在自己的指针处理里调用，没有新的全局函数包装。

## 行为

| 输入 | 电脑鼠标（pointerType = mouse，含 iPad 外接鼠标/触控板） | 触屏 / 笔 |
|---|---|---|
| 左键单击 | 只选取；点空地取消选择；Shift 加选/减选；双击 = 画面内同类（单位或建筑） | 不变（点地面仍是智能指令） |
| 左键拖动 | 框选：框里有单位只选单位，没有单位才选己方建筑；Shift 追加 | “框选”模式同一规则 |
| 右键 | 智能指令（移动/攻击/采集/修理/施工/登船/贸易）；只选了生产建筑时 = 给全部选中建筑设同一集结点；建造模式下右键取消 | — |
| A（+ 左键） | 按 A 进入攻击前进，左键点地面/敌人执行；按住 A 期间不再平移视角。F 保留为别名 | — |
| H | 原地待命（与“停止攻击”按钮同一 hold 指令） | — |
| 命令按钮（移动/攻击前进/设置集结点）后左键 | 执行该命令（明确选择的命令） | 不变 |
| 长按 | — | 单位：附近同类（原有）；建筑：画面内同类建筑（新增） |
| 编队 | Ctrl/Cmd + 1–6 编入（单位和建筑都可以），数字选回，双按定位 | “1–6”按钮 → 编入 → 组号（原有按钮，现在也收建筑） |
| 多座同类建筑点训练 | 交给队列最短的那座；一样短时轮流（联机副本还没收到上一条指令时也会轮到下一座） | 同 |

S 键仍是视角下移（WASD），没有改成“停止”；停止/待命用 H。Chrome 普通标签页里 Ctrl+1…8 被浏览器保留用于切换标签页，网页收不到；安装为 App 窗口、全屏或 Mac 上用 Cmd 时可用（原有编队机制同样如此）。

## 验证（2026-11-24，headless Chromium，非真机）

- `check-mouse-controls.cjs`（已加入 check-all）：15 项，含：左键点地面 0 条指令且清空选择；右键地面 move；A+左键 advance 且按住 A 时视角不动；敌方建筑左键只选中、右键 attack、H hold；建造模式左键预览、右键取消；框选规则；双击选 5 座兵营、Ctrl+1/1；5 次训练每座各 1 条（再 3 次后队列差 ≤1）；右键 5 条 rally 同一点；触屏点地面仍 move（同一测试在改动前的 expansion.js 上也通过，证明触屏未变）；触屏长按选同类建筑；触屏编队按钮编入/选回；触屏训练轮流；中英文提示文字。
- 界面检查（脚本截图 + DOM 量测，选中 6 座步兵营并点一次训练）：桌面 1280×720、手机竖屏 393×852、手机横屏 852×393、iPad 横屏 1180×820；中/英；命令栏展开/收起，共 16 个状态。“步兵营 × 6 / Barracks × 6”“已选择 6 座建筑 / Selected 6 buildings”无溢出；训练按钮 86–96 × 87–123 px，费用行“· ×6”换行显示、无溢出；“1–6”编队按钮 30–33 × 30–34 px（原有尺寸，未改）。
- 未验证：iPhone / iPad 真机触摸与 Safari；iPad 外接触控板的右键（双指点按）；真实联机下多建筑训练（逻辑走原有指令，联机冒烟只验证了 2 人同步）。
