# 小熊猫单机伙伴 v1

## 来自玩家的角色灵感

依据玩家女儿绘制的卡通小熊猫草图重新设计：圆脸黑白熊猫、金色小皇冠与红围巾。没有直接描摹或复用第三方游戏角色。

## 生成素材与处理

- 生成工具：OpenAI ImageGen；生成日期：2026-11-15。
- `src/panda-walk-v3-green.png`：6 帧 × 8 朝向步行 atlas。
- `src/panda-idle-v2-green.png`：4 帧 × 8 朝向待机、眨眼和挥手 atlas。
- `src/panda-attack-v2-green.png`：4 帧 × 8 朝向准备、挥爪、旋转跟随与收招 atlas。
- 输入图为统一纯绿底。`scripts/art/key-panda-atlas.cjs` 以绿幕色差生成透明边缘，并对半透明边缘去除绿幕污染；没有缩放、重绘或擦改角色帧。
- 游戏资源：`public/assets/panda-{walk,idle,attack}-v1.png`。游戏按玩家输入彩蛋后才加载三张图，不增加正常开局的解码或渲染成本。
- 原始的透明底生成尝试和测试性抠图没有接入游戏。三张最终 atlas 已在透明底查看：可见角色边缘整洁，角色主体无绿幕残边；八行对应正面、右前斜、右侧、右后斜、背面、左后斜、左侧、左前斜。

## 音效来源

- `public/audio/panda-twittering.ogg`：Mizunoryu 的真实大熊猫鸣叫录音，3.11 秒；原作者声明放弃版权并贡献至公有领域（PD-self）。运行时截取 1.6 秒用于召唤/选中提示。来源与登记见 `public/audio/CREDITS.md` 和 `public/audio/sources.json`。
- 未从影视、短视频或其他游戏提取音频。游戏仍须经浏览器用户手势解锁音频；本地自动化没有验证 iPhone/iPad 实机播放。

## 功能与审查状态

- 单机聊天框输入 `小熊猫` 可召唤一只；重复输入不会重复生成。只在单机有效，联机/多人状态会拒绝。
- 使用现有伙伴伤害、受击、选择和动画事件系统；单位数据为 16,000 生命、75 护甲、1,250 攻击，近战触及范围 82，受现有单机战斗规则控制。
- 静态 atlas 目视审查通过；已检查关键帧网格、透明背景与色键边缘。
- 尚未完成真实 Canvas 地图渲染顺序下的浏览器目视检查，也未在电脑 Chrome、iPhone 17 Safari 或 iPad 实测召唤、选中、缩放、帧动画和声音；因此不能记录为完整艺术签核或发布许可。
