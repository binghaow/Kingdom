# 电脑 AI：海战、运输登陆、空军——盘点与改造（v45）

分支 `feature/ai-naval-air`（基于 main b006cf3）。新模块 `public/ai-naval-air.js`，通过 `ai-humanlike.js` 里新建的
**AI 行为注册点**（`registerAIBehavior`）接入，不再新增 Sim 继承层，也没有包装任何函数。检查脚本 `check-ai-naval-air.cjs`。

## 1. 盘点范围

模拟链（`require` 顺序）：engine → empires → coalitions → dynasties → worlds → frontiers → siege → fortification → tactics →
companions → campaign → clarity → guardians → terrain → economy → wildlands → commander → roster → frontier-v40 →
**ai-humanlike**（← 新注册点，加载 ai-naval-air）→ network-model → network-commands / unit-intel / little-ant。

与海/空/运输相关的电脑逻辑分布：

| 位置 | 内容 |
|---|---|
| `empires.js` `ai()` | 最早的通用训练循环：遍历所有已建成的生产建筑；港口里渔船 < 3 先补渔船，否则 sloop（III 时代起 sloop/frigate）。建造计划里只有 `shipyard`（已退役），**从不新建港口**。 |
| `dynasties.js` / `worlds.js` `raids()` | 旧的“海上袭扰”：舰队去敌方港口。但 `commander.js` 对启用隐藏打法的电脑把 `nextRaid` 设成无穷大，**这段在现行对局里不运行**。 |
| `commander.js` | 隐藏打法：侦察（`aiScout`）、目标选择（`aiTarget`）、出兵波次（`aiLaunch`/`aiWaves`）。 |
| `companions.js` `armyFor` | 电脑“可用军队”：**排除所有舰船**，但包括飞行单位。 |
| `ai-humanlike.js` | v42 拟人打法（集结、撤退、微操、骚扰、防守），`aiTrainable` **排除 sea 与 air**。 |
| `frontier-v40.js` | v40 扩张：岛屿资源登陆（运村民 + 1–2 护卫上资源岛建采矿营地）、主攻时概率派小股侧翼“走海路”。 |
| `campaign.js` | 登船（`board`/`loadPassenger`，接载半径 165、运输船 6 人口）、轰炸机携弹 2 枚自动返航补弹。 |
| `roster.js` | 现行兵种：港口 渔船/运输船/轻型护航舰/重型护卫舰/迫击炮舰；飞艇工场 侦察热气球（III）/双翼轰炸机（V，需“航空工程”）；航母、舰载机、武装飞艇、运输飞艇已退役（玩家决定）。轰炸机**只能攻击建筑**。 |

## 2. 改造前 AI 会什么、不会什么、为什么

| 能力 | 改造前 | 原因（代码） |
|---|---|---|
| 建港口 | 只靠开局自带的港口；只有 v40 “岛屿资源登陆”在**没有任何港口**时会建一座 | 各层建造计划里没有 dock；`empires` 计划里的 `shipyard` 已退役 |
| 出战舰 | 会顺手出几艘（通用训练循环），但**没人指挥**，一直停在港口 | `armyFor` 排除舰船；唯一的舰队逻辑 `raids()` 被隐藏打法关闭 |
| 争夺制海权、护航、打渔船/海岸建筑 | 不会 | 没有任何读取敌方海军、下达舰队命令的代码 |
| 针对敌方海军造船 | 不会 | 侦察记忆 `aiIntel`/`seen` 只统计陆军，`aiTrainable` 排除 sea |
| 判断目标在另一块大陆 | 不会 | `aiTarget` 按直线距离挑最近的敌方城镇；主力 `advance` 到不可达点后原地不动，`aiWaves` 150 秒后作废，下一波重复 |
| 找到海岛上的敌人 | 基本不会 | `aiScout` 用陆军/村民去起始点，过不了海；热气球会优先当侦察兵，但没人造飞艇工场 |
| 装船、渡海、卸载、进攻 | 只有两种小规模：岛屿资源登陆（3 村民 + 1–2 护卫，一次）；主攻时 ≤30% 的侧翼走海路（要先有空运输船，不检查连通性、不护航、不回程） | 没有主力渡海流程 |
| 运输船被打撤退 / 回程接下一批 | 不会 | 同上 |
| 飞行单位 | 从不出 | 没有任何层会建飞艇工场；`aiTrainable` 排除 air；“龟缩”打法的偏好表里写了 bomber，但永远没有工场 |
| 空中骚扰、见防空撤退、配合主攻 | 不会 | 同上 |

基线实测（main b006cf3，本地 Node 模拟，潮汐群岛 straits 种子 7，3 席位：座位 0 空观察者，座位 1 大陆专家，座位 2 海岛专家，20 分钟）：
双方建筑血量 20 分钟内**只增不减**（谁也没打到谁）；登陆 0 次；飞行单位 0；两方各造了几艘战舰但从未出港。
座位 2 在 III 时代后陆军 93 人原地待命，座位 1 陆军 99 人原地待命。

## 3. 改造内容（玩家视角）

新模块按难度分级（`LEVEL` 表，入门/简单基本不变）：

- **港口**：有海且敌人在海对面时（II 时代起），在能通到敌岸的海域建港口；港口要先有村民走到岸边（派一名“跑腿”村民），
  岸边有敌舰时不选那里，开工后派远程兵站岗。港口只看连通海域（湖里的港口不算）。
- **战舰**：海对面有敌人时按时代补到目标数（专家 4 + 每时代 2，上限 12；困难 3/9；普通 2/6）；发现敌方战舰后按其战力
  针对性加造（III 时代起重型护卫舰为主）；敌方有海岸建筑时专家/困难补 1–2 艘迫击炮舰。只共享一个湖、没见过敌船时不造。
- **舰队**：敌舰靠近自己港口/渔船/运输船时，打得过就迎击（优先打运输船），打不过就回港；运输船出海时护航（舰队开在船前方）；
  掌握制海权时巡航到敌岸，打渔船、敌方港口和海岸经济建筑；受损过半或对方火力（含海岸要塞）占优就撤回。
- **渡海进攻**：主力的目标在另一块陆地时，接管这一波主力：部队走到港口附近一段开阔岸边，每艘运输船给每名乘客分配一个
  靠船的上船点（避免挤成一团上不去），**满载 6 人口**才开（专家/困难/普通；等太久才带不满的走），在远离敌方塔/要塞、
  离目标约 900 的岸段卸载，部队在滩头集结，等后续批次（或 45–55 秒）后一起进攻；运输船卸完立即回港接下一批；
  途中被打到血量低于阈值或火力压过护航就掉头回港，船上的兵在家卸下。滩头部队被打退时回滩头重整，不会去走一条走不通的回家路。
- **找到海对面的敌人**：没见过对方时，派一艘战舰沿可达海域去对方可能的出生点附近的海岸看一眼，或派热气球直接飞过去；
  看到任何敌方建筑就记下敌方基地位置（和陆地侦察兵一样）。
- **空军**：专家/困难 III 时代、普通 IV 时代建飞艇工场；热气球 1–2 只（一只侦察，一只跟在主力后面给炮兵观测）；
  V 时代研究航空工程，轰炸机专家 6 / 困难 4 / 普通 2。轰炸机两架以上编队：主力正在攻城时去炸对方塔/要塞/城镇中心
  （配合主攻）；否则定期去炸防空薄弱的经济建筑（磨坊、伐木场、采矿场、市场、港口、农田、房屋，离敌方城镇越远越优先），
  一次出击最多连炸 3 个目标；附近防空火力超过编队战力（按难度系数）或编队血量掉得太多就返航。轰炸机**只能炸建筑**
  （兵种设计如此，没有改），所以“打村民”靠炸采集点时的溅射，打落单陆军仍由原有骑兵骚扰负责。
- **难度**：入门/简单只在“陆路完全打不到任何敌人”时渡海（保证玩家在岛上也会被进攻），不造额外战舰、不出空军；
  普通开始有舰队和空军；困难更快更多；专家思考间隔 2.5 秒、2 艘运输船轮转、混编（陆军 + 舰队 + 迫击炮舰 + 热气球 + 轰炸机）。

## 4. 架构与约束

- **注册点**：`ai-humanlike.js` 新增 `registerAIBehavior({id, jobs, active, run, prewarm})`。`aiBehaviorStep()` 在每个模拟步
  **最多运行一个**到期的任务（所有电脑座位 × 行为 × 任务轮询），任务返回“多少秒后再来”。到期时间与游标存在
  `s.aiJobs`，行为自己的记忆存在 `s.aiNaval[team]`（随存档与同步，懒初始化，`Object.create` 重建也安全）。
- **预算**：每个任务一次只做一件事（一次 `view(team)`、一次单位遍历），用原有的 `aiAct` 令牌桶限制每秒命令数。
- **地形**：陆地连通区域沿用 `frontier-v40.js` 的 `landRegions`（现在按世界签名缓存，服务器/锁步每次重建世界不再重算）；
  海域连通区域与海岸列表在同一份缓存里，构造模拟时预热（`prewarm`），所以后期场景里不会出现首次计算尖峰。
  地形缓存是世界的纯函数，不进状态，不影响确定性。
- **确定性**：只读模拟状态，随机数只用 `sim.rand`；没有真实时间；同一局两次运行、每 10 秒按服务器方式存档→重建的两次运行结果都一致（检查 5）。
- **只有指令改变状态**：全部通过 `order / train / construct / research / unload` 这些电脑原本就在用的调用。
- 页面：所有加载 `ai-humanlike.js` 的页面在它前面加载 `ai-naval-air.js`；`sw.js` 缓存清单已加入，版本号加后缀
  `-ai-naval-air`；`sim-worker.js` 由 `npm run build` 重新打包。

## 6. 已知限制 / 未验证

- 轰炸机只能炸建筑（兵种设计），“骚扰村民”靠炸采集点溅射；骚扰落单陆军仍是骑兵的事。
- 大陆一方的旧港口在内湖时，要走很远去海边另建港口；被敌方舰队压制时港口可能反复被毁（专家对专家里海岛方常占上风）。
- 电脑不会撤离已登陆部队回本岛（被打退时回滩头重整、就地战斗）。
- 没有真机、真实联机多端长局验证；联机冒烟见发布报告。
