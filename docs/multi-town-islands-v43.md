# v43 多城镇中心与大岛屿

分支 `feature/multi-town-islands`（基于 main de89f8c）。检查脚本：`node check-multi-town.cjs`（已加入 check-all）；联机实测：`node scripts/netcode/live-multi-town.cjs`（需先 `node preview.cjs`）。

## A. 额外城镇中心

做法
- `engine.js`：`D.town` 改为 II 时代、275 木 + 100 石、建造 50 秒（要塞 40、统帅府 50 作参考）。`TOWN_RULES={max:3,gap:700}`（导出为 `K.townRules`）。
  `townRuleError` 在 engine / empires / worlds 三处 `placementError` 中统一检查：每方最多 3 座（含初始与地基），离己方城镇中心至少 700 px。其余地形、视野、资源、附近村民规则与其他建筑相同。
- `townOf(team)`：第一座存活且完工的城镇中心（主城存活时就是主城），否则任一存活的。模拟层 11 个文件里所有 `s.buildings.find(b=>b.team===…&&b.kind==='town')` 改用它（电脑大本营、推进时代、侦察、撤退、防守、进攻目标、援军、英雄撤退等）。
- 新城与原城同一定义：训练村民、所有资源的交付点（`depotFor` 本来就接受任意城镇中心）、+20 人口（总上限规则不变）。原城镇中心本身没有射击（`D.town` 无 damage），新城一致。
- 推进时代：原有 `researchError` 已禁止同一研究在任何建筑并行，第二座城镇中心会得到“研究已在进行中”。
- 失败判定：仍是“城镇中心被毁 → 出局”，只是在还有另一座**已完工**城镇中心时不再触发（只有一座城时与原规则完全相同；未完工地基不算）。这是“主城被拆后用剩下的城镇中心继续”的必要条件。
- 电脑（`ai-humanlike.js` `aiExpandTowns`，单机与服务器电脑座位共用，状态在 `s.aiTowns`，可存档、可 hydrate）：普通最多 +1（900 s 起），困难 +2（720 s 起），专家 +2（600 s 起），简单及以下不建。候选点 = 自己已占的资源点 / 岛屿登陆点 / 自己一侧资源点，520 px 内剩余资源需 ≥ 3500–5000，离敌方建筑 ≥ 900；同时只有一个地基。额外城镇中心空闲时也训练村民（总数仍受原村民目标限制）。
- 界面：村民建造菜单“经济”与“全部”页出现城镇中心（带 ⓘ，说明含费用、上限、700 距离、推进时代规则）；达到上限时按钮显示“每方最多 3 座城镇中心”。中英文均在 locale-data / locale-extra。

数据（`check-multi-town.cjs`，Node 无头模拟，lake_s 种子 5）
- 电脑首座分城：专家 604 s、困难 724 s，12.5 分钟内均到 3 座；简单 0。
- 专家电脑主城在 5 分钟时被毁后 4 分钟：村民 22 → 35，训练 83 个单位，不出局。
- 服务器式逐次 hydrate（3 席位含 2 电脑，straits），双方各有分城、电脑主城中途被毁：60 s 轮询正常。

## B. 岛屿

做法（`worlds.js` `islandShapes`，`frontier-v40.js` 1e）
- 海岸图（coast_s / coast_l / straits 下沿）：原来 3 个小岛 → 两座大侧岛（x=.3/.7 W，y=.885 H，半轴 .08 W × .055 H）+ 中央目标岛（.05 W × .032 H）。海峡图：海峡加宽（ry .105→.135 H），三座海峡岛加大（.045×.055 → .06×.075）。
- 岛屿范围内的陆地一律可通行：地图边缘噪声左右不对称，旧版右岛 27 格、左岛 6 格；现在左右镜像相等。
- 岛上原有随机森林换成公平资源包，并新增浆果：每人份额 金 14000 / 石 9000 / 木 7200 / 食物 3600（原 金 14000 / 石 9000 / 木 5400）。3–5 人局里不是每人都有“自己的岛”时，所有岛改为全员共享（原规则此时岛上只放 1800 木，没有争夺价值）。每节点储量随人数放大（人数/2 倍），节点数与 2 人局相当，避免服务器状态变大。
- 形状只依赖地图描述（种子、尺寸），服务器与客户端一致；`check-multi-town` 验证同种子两次生成节点完全相同。

- 新城建造时间 50 s、700 px 间距、电脑扩张时机是否合适；分城是否让电脑经济过强（专家 12 分钟内 3 座城）。
