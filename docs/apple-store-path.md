# 从网页验证到 App Store 下载

产品方向：供朋友共享和联机游玩的完整游戏，iPhone17横竖屏为主要终端，iPad横屏及电脑也要可用。网页部署只是当前验证阶段，不代表已经有iOS安装包或具备上架质量。

## 当前已具备
- 可分享的公开网页版、单机及联机基础、持续保存的美术和UI检查流程。
- 本次资源货物使用已有素材切片；缺少合适素材时留空并登记，不用临时几何图形充当成品。

## 后续验收阶段
1. 游戏版本稳定：补齐明确缺失的资产，检查内容一致性、触控、长局稳定性、资源加载、存档和朋友间联机完整流程。每项有实际结果及缺陷清单。
2. 可签名的iOS/iPadOS工程：确定客户端实现、构建环境和应用标识，处理全屏、安全区域、横竖屏、音频中断、后台恢复、离线内容、存档和网络错误。当前仓库未发现Swift、Xcode工程或Capacitor配置，本轮未创建或声称已有原生安装包。
3. 真机验证后通过TestFlight邀请朋友安装测试，记录机型、版本、帧率、内存、温度、耗电、触控、声音及断线恢复。该阶段需要可上传的应用构建及App Store Connect配置；外部测试首个构建需审核。见[Apple TestFlight](https://developer.apple.com/testflight/)。
4. 准备商店版本及准确的描述、截图、支持/隐私资料和素材来源台账，完成审核提交流程。上架验收以用户能从App Store下载并完成真实对局为准。Apple审核要求设备端测试及完整可用内容；单纯重新包装网站不足以作为质量验收。见[审核指南2.1与4.2](https://developer.apple.com/app-store/review/guidelines/)。

当前没有执行账号注册、购买、签名授权或商店提交。后续涉及这些具体步骤时再落实必要的信息与授权，不把当前的网页修复描述为已上架。
