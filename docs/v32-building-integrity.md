# V32 · 建筑碰撞、遮挡与渐进破损 · 2026-11-06

## 修复
- 建筑通行边界从单一中心圆扩展为与地基宽度对应的椭圆；屋顶投影不直接充当整块不可通行区。城墙/城门沿用原有连续碰撞与盟友开门逻辑；飞行单位仍可飞越。
- 地面/船只每次移动做2世界单位的分段检查，旧缓存路径和较长时间步不能穿过实体。施工时移出被新地基覆盖的单位；加载旧战局会检查并恢复卡在实体中的单位。出兵和卸载继续使用本域可通行位置。
- 从“仅树林后的己方农民”扩展为建筑、树林、矿物后所有当前可见单位的半透明轮廓；没有加入未进入视野的单位。鼠标优先命中真实单位像素，便于选中或攻击被建筑挡住的单位。轮廓采用与普通单位相同的插值位置，避免额外触发步行动画抖动。
- 建筑血量>70%完好，33–70%轻损，≤33%重损。裂墙、断梁、缺瓦、焦痕按原建筑轮廓合成，重损增加交叉混合的火焰与烟。维修后按血量退回轻损和完好，不永久烘焙损伤。
- 倒塌保留原国家建筑外形与材料：短暂重损停留，5块原建筑切片渐落，再出现扬尘与瓦砾，最后废墟渐隐。替换原先挤扁房屋加矩形瓦砾的表现。
